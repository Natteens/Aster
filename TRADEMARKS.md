# Aster project identity

“Aster” is the name used to identify the language and project maintained in the official
[Natteens/Aster](https://github.com/Natteens/Aster) repository. This document does not claim that
Aster is a registered trademark.

The software license permits forks and derivative works. You may accurately say that software is
derived from Aster, compatible with Aster, or intended for Aster. Articles, tutorials, integrations,
and unmodified redistribution may use the name to identify the project and its origin.

When distributing a significantly modified version, use a distinct project, package, executable,
extension, and visual identity if users could otherwise mistake it for the official Aster project.
State that the work is modified, identify its upstream origin, and do not imply endorsement,
approval, or maintenance by the official project.

Avoid names or presentation that are confusingly similar to the official project for a fork,
domain, account, package, or editor extension. No official logo policy exists at this time.

This is an identity and attribution policy, not an additional software license. It does not limit
the rights granted by Aster's software licenses or prevent factual, descriptive use of the name.
